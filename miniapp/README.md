# Mini App — как запустить для работы над дизайном

Ничего настраивать не нужно: ни Telegram, ни базы, ни ключей. Вне Telegram
приложение само поднимает фейковый бэкенд с реалистичными данными — работают
все экраны, шторки и графики.

    git clone https://github.com/Myxabzbzzz/planner.git
    cd planner/miniapp
    git checkout -b design-friend
    npm install
    npm run dev

Дальше открыть адрес, который напечатает Vite (обычно `http://localhost:5173`),
и включить режим телефона: DevTools → Toggle device toolbar → 390×844.

Нужен **Node 22.12 или новее** (`node -v`). Если версия старее, `npm install`
отвалится на `engines`.

## Флаги в адресе

Дописываются к адресу: `http://localhost:5173/?theme=dark`

| Флаг | Что показывает |
| --- | --- |
| `?theme=dark` | тёмная тема |
| `?theme=light` | светлая тема |
| `?mock=empty` | первый день: все экраны пустые |
| `?mock=noaccess` | экран «Нет доступа» |

Без `?theme=` вне Telegram открывается светлая тема — так сообщает Telegram SDK
в обычном браузере. Внутри Telegram тема берётся из настроек клиента.

Флаги комбинируются: `?theme=dark&mock=empty`.

## Где что лежит

| Путь | Что это |
| --- | --- |
| `src/styles.css` | вся дизайн-система: токены, компоненты, обе темы |
| `src/components/` | кнопки, шторки, графики, табы |
| `src/screens/` | экраны: Сегодня, Задачи, Деньги, Привычки, Заметки, Профиль, Уточнить |
| `src/devMock.ts` | тестовые данные — можно править, чтобы посмотреть другие состояния |
| `../docs/design/miniapp-v2.md` | решения по дизайну и почему они такие |

Цвета и отступы правятся в одном месте — в `:root` и `:root[data-theme="light"]`
в начале `src/styles.css`. Менять их в компонентах не нужно.

## Проверка перед коммитом

    npm run build   # типы + сборка
    npm test        # тесты логики

Контраст цветов проверен по WCAG: обычный текст не ниже 4.5:1, акцентная заливка
не ниже 3:1. Если меняешь токены, стоит пересчитать — иначе текст может стать
нечитаемым на телефоне при солнце.
